## Overview

Soundtoys Radiator models the Altec 1567A tube mixing amplifier, an extremely rare piece of hardware known for its lush harmonic distortion and unique transformer coloration.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtoys Radiator** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **1567A Model** | Accurate circuit simulation of the Altec 1567A tube mixer amplifier |
| **Transformer Color** | Input and output transformer emulation for magnetic saturation |
| **Triode Warmth** | Triode tube circuit adds rich even-order harmonic distortion |
| **Mix Insert** | Use as a subtle warming insert or dial in extreme tube saturation |
